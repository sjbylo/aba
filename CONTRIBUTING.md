# Contributing to ABA

Contributions of any kind are welcome — bug reports, feature ideas, documentation improvements, or code.

## Reporting issues

Open an issue at https://github.com/sjbylo/aba/issues with a clear description of the problem and steps to reproduce.

## Questions and ideas

Start a discussion at https://github.com/sjbylo/aba/discussions.

## Code contributions

1. Fork the repo and create a branch from `dev`.
2. Make your changes — follow the existing coding style (tabs, no trailing whitespace).
3. Run `build/pre-commit-checks.sh` before committing.
4. Open a pull request against `dev`.
